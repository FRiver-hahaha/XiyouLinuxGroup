## 🔑 关键修复点

### 1. LIST 命令修复

**问题**: 每次 LIST 都重新分配端口，与 PASV 分配的端口不一致

```
修复前: PASV(5001) ──► LIST(5002) ❌ 端口不匹配
修复后: PASV(5001) ──► LIST(5001) ✅ 使用 session 保存的端口
```

### 2. CWD 命令修复

**问题**: 只返回消息，未实际更新 workingDir

```cpp
// 修复前
send("目录已更改\r\n");  // workingDir 未变

// 修复后
session->workingDir = newDir;  // 实际更新
send("250 目录已更改为 " + newDir + "\r\n");
```

### 3. 响应码标准化

```
修复前: "登录成功", "传输完成"
修复后: "230 登录成功", "226 传输完成"
```

## 📋 FTP 响应码速查

| 代码 | 含义 | 触发命令 |
|:----:|------|----------|
| 150 | 准备传输 | LIST, RETR, STOR |
| 200 | 命令成功 | TYPE |
| 220 | 服务就绪 | 连接时 |
| 221 | 再见 | QUIT |
| 226 | 传输完成 | LIST, RETR, STOR |
| 227 | 被动模式 | PASV |
| 230 | 登录成功 | USER, PASS |
| 250 | 操作成功 | CWD, CDUP |
| 257 | 当前目录 | PWD |
| 425 | 数据连接失败 | - |
| 500 | 语法错误 | 空命令 |
| 501 | 参数错误 | 缺少参数 |
| 502 | 未实现 | 未知命令 |
| 550 | 文件不存在 | RETR, CWD |
