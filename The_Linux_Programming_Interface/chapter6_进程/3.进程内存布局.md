## 6.3 进程内存布局

- 内存段：栈、堆、未初始化数据段(BSS)、初始化数据段、代码段。

- 内存布局：从低地址到高地址，依次为代码段、初始化数据段、未初始化数据段、堆、栈。栈从高地址向低地址生长。在数据段上保存了全局变量和静态变量，其本质是占用了磁盘的大小，由于程序存储在磁盘上，因此对于未初始化的全局数据，没有必要额外为他们分配磁盘空间，因此区分开两者。

- 变量的类型：局部变量、全局变量、静态变量、动态分配变量、寄存器变量。

- 栈：局部变量、实际参数、返回值。
- 堆：动态分配变量。
-  BSS 段：未初始化的全局变量和静态变量。
- 初始化数据段：初始化的全局变量和静态变量。
- 代码段：又叫文本段。有只读特性，可多进程共享。
