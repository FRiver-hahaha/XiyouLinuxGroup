## 命令行参数和环境列表

- 命令行参数：'''int argc, char* argv[]'''

- argc：参数数量。
- argv：参数。

- 环境：含有当前进程的全部信息。
- 环境列表：保存了环境变量。
- 环境变量：描述进程内不同命令的变量。

- 特性：环境的继承会随着进程的创建而继承。但父子进程却有保持着相互的隔离，即各自的修改互不影响，但子进程会在创建前继承父进程的环境列表。

- 访问环境：在 shell 内可执行 printenv，查看进程内的环境。在 c 库中，也有getenv() 函数，获取环境变量，参数为字符串变量名字，返回字符串指针。
- 修改环境：putenv(), setenv()，unsetenv(), clearenv()。
