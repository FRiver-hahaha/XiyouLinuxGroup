# fork(), exit(), wait()以及execve()的简介
- fork()：  
    允许在父进程下创建子进程，子进程获得父进程的栈段，数据段，堆，可执行文本段的拷贝。
- exit()：  
    退出当前进程，并且把占用资源交还给内核。
- wait(&status):  
status:子进程状态  
    1. 在子进程没有使用exit()终止，父进程会被挂起直至子进程终止。
    2. 返回子进程的终止状态。
- execve(pathname, argv, envp)  
    pathname:路径名字  
    argv:参数列表  
    envp:环境变量列表  
    在当前进程的内存中加载一个新程序。

- `SIGCHLD`信号:告诉父进程，某一个子进程已终止。
