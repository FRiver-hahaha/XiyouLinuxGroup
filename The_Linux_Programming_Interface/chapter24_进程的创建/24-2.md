# 创建新进程: fork()
在诸多应用中，创建多个进程是任务分解时行之有效的方式。例如，某一网络服务器进程可以在侦听客户端请求的同时，为处理每一个请求而创建一个新的子进程，与此同时，服务器会继续侦听更多客户端请求，提高了系统的并发性。(即，可同时处理多个任务和请求。)

- fork():  

    1. 位置: #include <unistd.h>
    2. 参数:void  
    3. 返回值:-1(创建失败)， pid_t(子进程的pid)， 0(子进程内部的返回值，表示创建成功)。

- 习惯写法: 
```
switch(childpid = fork()) {
    case -1: 
        /* 处理错误 */
    case 0: 
        /* 子进程下的操作 */
    default:// 成功创建进程之后的操作
        /* 父进程下的操作 */
}
```
