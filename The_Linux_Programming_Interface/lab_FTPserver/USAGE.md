# FTP 服务器使用说明

## 修复内容

### 1. LIST 命令无法工作
**问题原因**：每次 LIST 都创建新的监听套接字并分配新端口，但客户端在 PASV 后已经连接到之前分配的端口。

**修复方案**：
- 使用 session 中保存的 `pasvPort`，而不是每次都重新分配
- 确保 PASV 和 LIST 使用相同的端口

### 2. 无法切换目录 (CWD)
**问题原因**：CWD 命令只返回"目录已更改"，但没有实际更新 `workingDir`。

**修复方案**：
- 新增 `handleCwdCommand()` 函数，实际处理目录切换逻辑
- 支持绝对路径和相对路径
- 规范化路径（处理 `..` 和 `.`）
- 检查目录是否存在
- 新增 `CDUP` 命令支持返回上级目录

### 3. 上传下载不人性化
**问题原因**：缺少清晰的提示和正确的 FTP 响应码。

**修复方案**：
- 使用标准 FTP 响应码（150/226/227/230 等）
- 客户端微壳添加更多友好命令（`ls`, `cd`, `pwd`, `help`）
- 显示文件大小和传输状态

## 启动服务器

```bash
cd /home/friver/gitclone/XiyouLinuxGroup/The_Linux_Programming_Interface/Lab_NameServer
./bin/ftpserver
```

服务器将在以下端口启动：
- 控制端口：2100
- 数据端口：2000
- 被动模式端口：5000-5100

## 连接客户端

```bash
./bin/ftpclient
```

或者使用系统 FTP 客户端：
```bash
ftp 127.0.0.1 2100
# 匿名登录，用户名：anonymous，密码：anonymous@
```

## 支持的命令

### 客户端内置命令（微壳）
| 命令 | 说明 |
|------|------|
| `list` / `ls` | 列出远程文件 |
| `get <文件名>` | 下载文件 |
| `put <文件名>` | 上传文件 |
| `cd <目录>` | 切换目录 |
| `cdup` / `cd ..` | 返回上级目录 |
| `pwd` | 显示当前目录 |
| `help` / `?` | 显示帮助 |
| `quit` / `exit` | 退出 |
| `pasv` | 进入被动模式 |

### 标准 FTP 命令
| 命令 | 响应码 | 说明 |
|------|--------|------|
| `USER anonymous` | 230 | 用户登录 |
| `PASS anonymous@` | 230 | 密码验证 |
| `PASV` | 227 | 进入被动模式 |
| `LIST` | 150 → 226 | 列出目录 |
| `RETR <文件>` | 150 → 226 | 下载文件 |
| `STOR <文件>` | 150 → 226 | 上传文件 |
| `PWD` | 257 | 显示当前目录 |
| `CWD <目录>` | 250 | 切换目录 |
| `CDUP` | 250 | 返回上级 |
| `QUIT` | 221 | 退出 |
| `HELP` | 214 | 显示帮助 |
| `FEAT` | 211 | 显示功能列表 |
| `SYST` | 215 | 显示系统类型 |
| `TYPE A` | 200 | 设置传输类型 |

## 注意事项

1. **被动模式**：所有数据传输都使用被动模式（PASV），确保防火墙不会阻止连接
2. **匿名登录**：服务器支持匿名登录，无需密码
3. **目录权限**：确保服务器有权限读取/写入目标目录
4. **端口范围**：被动模式使用端口 5000-5100，确保这些端口未被占用

## 故障排查

### LIST 命令失败
- 确保先执行 `PASV` 命令
- 检查防火墙是否允许被动模式端口（5000-5100）
- 查看服务器日志确认端口分配

### 无法切换目录
- 确认目录存在
- 使用绝对路径（如 `cd /bin`）或相对路径（如 `cd bin`）
- 使用 `pwd` 查看当前目录

### 文件传输失败
- 检查文件路径是否正确
- 确认文件权限
- 查看服务器日志
