## 二、核心业务流程

### 2.1 服务器启动流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                          main() 函数                                 │
└─────────────────────────┬───────────────────────────────────────────┘
                          │
                          ▼
              ┌───────────────────────┐
              │ 创建 Server 对象        │
              │ controlPort = 2100    │
              │ dataPort = 2000       │
              │ threadPool = 4 线程    │
              └───────────┬───────────┘
                          │
                          ▼
              ┌───────────────────────┐
              │ Server.start()        │
              │                       │
              │ 1. socket() 控制套接字 │
              │ 2. bind() :2100       │
              │ 3. listen()           │
              │ 4. socket() 数据套接字 │
              │ 5. bind() :2000       │
              │ 6. epoll_create1()    │
              │ 7. epoll_ctl(ADD)     │
              └───────────┬───────────┘
                          │
                          ▼
              ┌───────────────────────┐
              │ Server.run()          │
              │                       │
              │ while(running) {      │
              │   epoll_wait()        │
              │   处理事件...         │
              │ }                     │
              └───────────────────────┘
```

## 三、数据结构

### 3.1 FtpSession 会话结构

```
┌─────────────────────────────────────────────────────────────────────┐
│                        FtpSession                                   │
├─────────────────────────────────────────────────────────────────────┤
│  controlSock: int      控制连接套接字 (始终连接)                     │
│  dataSock: int         数据连接套接字 (传输时临时使用)               │
│  pasvListenSock: int   PASV 监听套接字 (PASV 后创建)                 │
│  pasvPort: int         被动模式端口号 (5000-5100)                   │
│  clientIp: string      客户端 IP 地址                                │
│  workingDir: string    当前工作目录 (默认"/")                       │
│  pasvMode: bool        是否处于被动模式                             │
└─────────────────────────────────────────────────────────────────────┘

会话生命周期:
  创建 → 新客户端连接时
  使用 → 整个 FTP 会话期间
  销毁 → QUIT 或连接断开时
```

## 七、命令处理决策树

```
handleFtpCommand(command)
│
├─→ USER → 返回 230 (匿名登录)
│
├─→ PASS → 返回 230 (匿名登录)
│
├─→ PASV → handlePasvCommand()
│          ├─→ 关闭旧的 pasvListenSock
│          ├─→ 分配新端口 (nextPasvPort++)
│          ├─→ 创建监听套接字
│          ├─→ 保存到 session
│          └─→ 返回 227
│
├─→ LIST → handleListCommand()
│          ├─→ 检查 session.pasvPort
│          ├─→ 发送 150
│          ├─→ accept 数据连接
│          ├─→ listDirectory()
│          ├─→ 发送目录数据
│          ├─→ 关闭数据连接
│          └─→ 返回 226
│
├─→ RETR → handleRetrCommand(filename)
│          ├─→ 构建文件路径
│          ├─→ readFile()
│          ├─→ 发送 150
│          ├─→ accept 数据连接
│          ├─→ 发送文件数据
│          ├─→ 关闭数据连接
│          └─→ 返回 226
│
├─→ STOR → handleStorCommand(filename)
│          ├─→ 构建文件路径
│          ├─→ 发送 150
│          ├─→ accept 数据连接
│          ├─→ 接收文件数据
│          ├─→ 关闭数据连接
│          ├─→ saveFile()
```
