总结

该任务包含三个独立但完整的编程小项目，分别涉及 文本处理与词频统计、学生成绩数据清洗与统计分析及可视化、以及 中文文本预处理与词云生成。下面对每个部分的主要内容进行详细总结：

一、英文文章词频统计并输出Top10高频词

功能描述：

编写一个 Python 程序，完成以下任务：

1. 文件读取
   - 读取指定路径下的文本文件 
"article.txt"（内容为英文，含标点、大小写等）。
   - 若文件不存在，捕获 
"FileNotFoundError" 异常，并提示用户：“文件路径错误，请检查文件是否存在”。
2. 文本预处理
   - 将所有字符转换为小写。
   - 去除所有标点符号（包括：
"!"#$%&'()*+,-./:;<=>?@[\]^_"{|}~` 及空白字符）。
   - 去除多余空白（比如多空格、制表符等也要处理，只保留纯净的单词）。
3. 单词统计
   - 统计每个单词出现的频率。
   - 忽略长度 ≤ 2 的单词（如 "a", "is", "at" 等短词不参与统计）。
4. 排序与输出
   - 按词频从高到低排序。
   - 取前 10 个高频词。
   - 将结果写入新文件 
"top10_words.txt"，每行格式为：
排名 单词 频率
例如：
1 python 28
2 code 25
...

二、学生成绩数据处理、统计与可视化

功能描述：

基于一个学生成绩的 CSV 文件 
"scores.csv"，完成数据读取、清洗、统计和可视化，具体包括：

1. 数据读取与基本查看

- 使用 
"pandas" 读取 
"scores.csv" 文件，字段包括：姓名, 学号, 语文, 数学, 英语, 理综, 考试日期
- 查看数据的基本信息，包括：
   - 各字段的数据类型（dtype）
   - 每列的缺失值数量

2. 数据清洗

- 删除所有存在缺失值的行（即只要某行有 NaN，就整行删除）。
- 剔除异常值：各科成绩（语文、数学、英语、理综）必须在 
"[0, 150]" 范围内，超出此范围的行要删除（比如成绩为负数或者大于150的异常数据）。
- 新增“总分”列：将 语文 + 数学 + 英语 + 理综 的成绩求和，作为新的一列“总分”。

3. 数据统计

- 计算各科（语文、数学、英语、理综）的平均分。
- 计算“总分”列的中位数。
- 将上述统计结果保存到文本文件 
"score_statistics.txt" 中，要求格式清晰可读（比如分行展示，有适当标题或说明）。

4. 数据可视化

- 使用 
"matplotlib" 绘制 “各科平均分柱状图”，具体要求：
   - 图表标题：“学生各科平均分统计”
   - x 轴：科目名称（如 语文、数学、英语、理综）
   - y 轴：对应科目的平均分
   - 设置合适的坐标轴标签、图例（如有需要），使图表清晰易懂
   - 将图表保存为图片文件 
"score_bar.png"，分辨率设置为 100 dpi

三、中文文本词云生成

功能描述：

编写程序，读取用户指定的中文文本文件 
"content.txt"，对其进行预处理并生成词云图，具体流程如下：

1. 文本读取与判空

- 读取用户指定的文本文件 
"content.txt"（支持中文内容）。
- 额外要求：如果该文件内容为空（即文件存在但没有任何有效字符或全是空白），则提示用户：“文本文件内容为空，无法生成词云”，程序终止词云生成。

2. 文本预处理

- 对中文文本进行预处理，去除其中的中文停用词。
   - 停用词从文件 
"stopwords.txt" 中读取，每行一个停用词（如“的”、“是”、“和”等无实际意义的常用虚词）。
   - 要求根据停用词表过滤掉这些词，避免它们出现在词云中。

3. 词云生成与展示

- 使用 
"wordcloud" 库生成词云图，具体自定义配置如下：
   - 背景色为白色
   - 最大显示单词数为 100
   - 字体设置为支持中文的系统字体，例如：
      - Windows 系统可使用 
""SimHei.ttf""（黑体）
      - macOS 系统可使用 
""Arial Unicode.ttf""
      - （需确保该字体文件存在，或者提供字体路径）
   - 使用 
"matplotlib" 将生成的词云图 显示出来，并且 保存为图片文件 
"wordcloud_result.png"

总结归纳

项目 主要功能 涉及技术/库 关键点/要求
